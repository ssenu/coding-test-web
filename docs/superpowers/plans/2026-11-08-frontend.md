# 프런트엔드 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설계 문서(`docs/superpowers/specs/2026-11-08-coding-test-web-design.md`) 5장의 관리자 화면 5개와 참가자 화면 3개를 Vue로 만들어, 이미 완성된 백엔드 API·웹소켓과 연결한다.

**Architecture:** 화면과 무관한 계산(그래프 변환, 승인 묶음, 편집기 초기값, 재접속)은 `src/lib`의 순수 함수로 두고 Vitest로 테스트한다. 화면은 REST로 상태를 받고, 웹소켓 이벤트가 오면 상태를 다시 받는다(팀 초안만 바로 반영). 상태 관리 라이브러리는 쓰지 않는다.

**Tech Stack:** Vue 3.5, Vite 8, TypeScript 5.9(vue-tsc), vue-router 5, Vue Flow 1.48, CodeMirror 6, marked + DOMPurify; 테스트는 Vitest 5 + @vue/test-utils + jsdom.

## 이 계획의 범위

계획 2/3이다. 백엔드(계획 1)는 `main`에 병합돼 있다. 배포(Dockerfile, 정적 파일 서빙, Playwright 전체 흐름)는 계획 3에서 다룬다.

## Global Constraints

- 사용자에게 보이는 문구는 한국어.
- 문제 마크다운은 `renderMarkdown`(DOMPurify)을 거친 HTML만 `v-html`로 넣는다. 다른 곳에서 `v-html` 금지.
- 참가자 토큰은 localStorage `ctw.participant`, 개인 단계 임시본은 `ctw.draft.{runId}.{boxId}`.
- 웹소켓 재접속 간격 0.5초 시작, 두 배씩, 최대 10초. 4401/4404면 재접속하지 않는다.
- 팀장 초안 전송은 0.5초 debounce, typing 신호는 5초 throttle.
- 개발 서버는 `/api`, `/ws`를 `http://localhost:8000`으로 프록시한다.
- 모든 명령은 `frontend/`에서 실행한다.

## API와 이벤트 계약

백엔드(`backend/app`)가 이미 제공하는 것을 프런트엔드가 쓰는 범위만 정리했다.

**인증**
- 관리자: `POST /api/admin/login {password}` → HttpOnly 쿠키 `admin_session`. 같은 출처 요청에 자동으로 실린다.
- 참가자: `POST /api/p/join {entry_code, name}` → `{status: "joined"|"pending", token, participant_id, run_id}`. 이후 요청은 헤더 `X-Participant-Token`. `pending` 토큰으로 `/api/p/state`를 부르면 409, 승인되면 200.
- 오류 본문은 `{"detail": 문자열}`. 승인 시 미제출이 있으면 `409 {"detail": {"code": "unsubmitted", "box_ids": [...], "message": "..."}}`.

**웹소켓** `/ws/runs/{run_id}` (관리자는 쿠키, 참가자는 `?token=`)
- 서버 → 클라이언트 `{event, data}`:

| 이벤트 | 받는 쪽 | data | 화면 처리 |
|---|---|---|---|
| `participant_updated` | 관리자 | 참가자 전체 정보 | 상태 다시 받기 |
| `assignment_updated` | 참가자 | `{id, name, assigned_box_id, is_leader}` | 상태 다시 받기 |
| `participant_removed` | 모두 | `{id}` | 참가자: 내 id면 입장 화면으로 |
| `box_state_changed` | 모두 | `{box_id, state}` | 상태 다시 받기 |
| `run_status_changed` | 모두 | `{status}` | 상태 다시 받기 |
| `box_content_updated` | 모두 | `{box_id}` | 상태 다시 받기 |
| `edge_approved` | 모두 | `{edge_id}` | 상태 다시 받기 |
| `submission_received` | 관리자 | `{box_id, participant_id, submitted_at}` | 상태 다시 받기 |
| `team_draft` | 팀장 외 참가자 | `{box_id, files, updated_at}` | 팀 파일에 바로 반영 |
| `team_version_saved` | 모두 | 버전 요약 | 상태 다시 받기 |
| `error` | 보낸 사람 | `{detail}` | (무시) |

- 클라이언트 → 서버: `{"type": "typing"}`(5초에 한 번), `{"type": "team_draft", "box_id", "files"}`(팀장, 0.5초 묶음), `{"type": "ping"}`.
- 인증 실패는 연결 후 4401, 없는 회차는 4404로 닫힌다. 이때는 다시 붙지 않는다.
- 원칙: 이벤트는 "무언가 바뀌었다"는 신호로 쓰고 실제 데이터는 REST로 다시 받는다(재접속 때도 같다). `team_draft`만 예외.

`frontend/tests/api.test.ts`:

```ts
import { afterEach, beforeEach, describe, expect, it, vi } from 'vitest'
import {
  ApiError,
  adminApi,
  clearParticipant,
  loadParticipant,
  participantApi,
  saveParticipant,
} from '../src/lib/api'

function respond(status: number, body?: unknown) {
  return new Response(body === undefined ? null : JSON.stringify(body), {
    status,
    headers: { 'Content-Type': 'application/json' },
  })
}

const fetchMock = vi.fn()

beforeEach(() => {
  fetchMock.mockReset()
  vi.stubGlobal('fetch', fetchMock)
  localStorage.clear()
})
afterEach(() => vi.unstubAllGlobals())

describe('참가자 토큰 보관', () => {
  it('저장, 읽기, 지우기', () => {
    expect(loadParticipant()).toBeNull()
    saveParticipant({ token: 't', runId: 1, participantId: 2 })
    expect(loadParticipant()).toEqual({ token: 't', runId: 1, participantId: 2 })
    clearParticipant()
    expect(loadParticipant()).toBeNull()
  })

  it('깨진 값은 없는 것으로 본다', () => {
    localStorage.setItem('ctw.participant', '{oops')
    expect(loadParticipant()).toBeNull()
  })
})

describe('request', () => {
  it('JSON 본문을 보내고 응답을 돌려준다', async () => {
    fetchMock.mockResolvedValue(respond(200, { ok: true }))
    await expect(adminApi.login('pw')).resolves.toEqual({ ok: true })
    const [url, init] = fetchMock.mock.calls[0]!
    expect(url).toBe('/api/admin/login')
    expect(init).toMatchObject({ method: 'POST', body: '{"password":"pw"}', credentials: 'same-origin' })
    expect(init.headers['Content-Type']).toBe('application/json')
    expect(init.headers['X-Participant-Token']).toBeUndefined()
  })

  it('참가자 요청에는 토큰 헤더를 붙인다', async () => {
    saveParticipant({ token: 'tok', runId: 1, participantId: 2 })
    fetchMock.mockResolvedValue(respond(200, { box_id: 'a', submitted_at: 'x' }))
    await participantApi.submit('a', { 'a.py': 'x' })
    const [url, init] = fetchMock.mock.calls[0]!
    expect(url).toBe('/api/p/boxes/a/submit')
    expect(init.headers['X-Participant-Token']).toBe('tok')
    expect(JSON.parse(init.body)).toEqual({ files: { 'a.py': 'x' } })
  })

  it('204는 undefined를 돌려준다', async () => {
    fetchMock.mockResolvedValue(respond(204))
    await expect(adminApi.deleteTemplate(1)).resolves.toBeUndefined()
  })

  it('실패하면 detail 문자열을 메시지로 갖는 ApiError를 던진다', async () => {
    fetchMock.mockResolvedValue(respond(409, { detail: '이 단계는 닫혔습니다.' }))
    const err = await participantApi.submit('a', {}).catch((e: unknown) => e)
    expect(err).toBeInstanceOf(ApiError)
    expect(err).toMatchObject({ status: 409, message: '이 단계는 닫혔습니다.' })
  })

  it('detail이 객체면 message를 쓰고 원본도 남긴다', async () => {
    const detail = { code: 'unsubmitted', box_ids: ['b'], message: '아직 제출하지 않은 파트가 1개 있습니다.' }
    fetchMock.mockResolvedValue(respond(409, { detail }))
    const err = (await adminApi.approve(1, ['b-team'], false).catch((e: unknown) => e)) as ApiError
    expect(err.message).toBe(detail.message)
    expect(err.detail).toEqual(detail)
  })

  it('검증 오류 배열은 일반 문구로 바꾼다', async () => {
    fetchMock.mockResolvedValue(respond(422, { detail: [{ loc: ['body'], msg: 'bad' }] }))
    await expect(adminApi.createTemplate('')).rejects.toThrow('입력값을 확인하세요.')
  })

  it('첨부 파일은 FormData로 올린다', async () => {
    fetchMock.mockResolvedValue(respond(201, { id: 1, box_id: 'a', filename: 'x.txt', size: 1 }))
    await adminApi.uploadTemplateFile(3, 'a', new File(['x'], 'x.txt'))
    const [url, init] = fetchMock.mock.calls[0]!
    expect(url).toBe('/api/templates/3/files')
    expect(init.body).toBeInstanceOf(FormData)
    expect((init.body as FormData).get('box_id')).toBe('a')
    expect(init.headers['Content-Type']).toBeUndefined()
  })
})
```

interface RequestOptions {
  body?: unknown
  form?: FormData
  participant?: boolean
}

async function request<T>(method: string, path: string, options: RequestOptions = {}): Promise<T> {
  const headers: Record<string, string> = {}
  let body: BodyInit | undefined
  if (options.form) {
    body = options.form
  } else if (options.body !== undefined) {
    headers['Content-Type'] = 'application/json'
    body = JSON.stringify(options.body)
  }
  if (options.participant) {
    const p = loadParticipant()
    if (p) headers['X-Participant-Token'] = p.token
  }
  const res = await fetch(path, { method, headers, body, credentials: 'same-origin' })
  if (!res.ok) {
    const data = await res.json().catch(() => ({}))
    throw new ApiError(res.status, (data as { detail?: unknown }).detail ?? res.statusText)
  }
  if (res.status === 204) return undefined as T
  return (await res.json()) as T
}

export interface Debounced<A extends unknown[]> {
  (...args: A): void
  flush(): void
  cancel(): void
}

export function debounce<A extends unknown[]>(fn: (...args: A) => void, wait: number): Debounced<A> {
  let timer: ReturnType<typeof setTimeout> | null = null
  let pending: A | null = null
  const run = () => {
    timer = null
    if (pending) {
      const args = pending
      pending = null
      fn(...args)
    }
  }
  const debounced = ((...args: A) => {
    pending = args
    if (timer) clearTimeout(timer)
    timer = setTimeout(run, wait)
  }) as Debounced<A>
  debounced.flush = () => {
    if (timer) clearTimeout(timer)
    run()
  }
  debounced.cancel = () => {
    if (timer) clearTimeout(timer)
    timer = null
    pending = null
  }
  return debounced
}

/** interval ms에 한 번만 실행한다(첫 호출은 바로). */
export function throttle<A extends unknown[]>(fn: (...args: A) => void, interval: number): (...args: A) => void {
  let last = -Infinity
  return (...args: A) => {
    const now = Date.now()
    if (now - last >= interval) {
      last = now
      fn(...args)
    }
  }
}

// 서버는 인증 실패 시 4401, 없는 회차면 4404로 닫는다. 이때는 재접속하지 않는다.

export interface ServerEvent {
  event: string
  data: Record<string, unknown>
}

export interface SocketHandlers {
  onEvent: (event: ServerEvent) => void
  onOpen?: () => void
  onAuthFailed?: (code: number) => void
}

type WebSocketCtor = new (url: string) => WebSocket

export const AUTH_FAIL_CODES = [4401, 4404]
const BASE_DELAY_MS = 500
const MAX_DELAY_MS = 10_000

export function runSocketUrl(runId: number, token?: string, loc: Location = window.location): string {
  const proto = loc.protocol === 'https:' ? 'wss' : 'ws'
  const query = token ? `?token=${encodeURIComponent(token)}` : ''
  return `${proto}://${loc.host}/ws/runs/${runId}${query}`
}

export function reconnectDelay(attempt: number): number {
  return Math.min(BASE_DELAY_MS * 2 ** attempt, MAX_DELAY_MS)
}

export class RunSocket {
  private ws: WebSocket | null = null
  private attempt = 0
  private timer: ReturnType<typeof setTimeout> | null = null
  private stopped = false
  private readonly url: string
  private readonly handlers: SocketHandlers
  private readonly Impl: WebSocketCtor

  constructor(url: string, handlers: SocketHandlers, Impl: WebSocketCtor = WebSocket) {
    this.url = url
    this.handlers = handlers
    this.Impl = Impl
  }

  start(): void {
    this.stopped = false
    this.connect()
  }

  stop(): void {
    this.stopped = true
    if (this.timer) clearTimeout(this.timer)
    this.timer = null
    this.ws?.close()
    this.ws = null
  }

  send(message: Record<string, unknown>): boolean {
    if (!this.ws || this.ws.readyState !== 1) return false
    this.ws.send(JSON.stringify(message))
    return true
  }

  private connect(): void {
    const ws = new this.Impl(this.url)
    this.ws = ws
    ws.onopen = () => {
      this.attempt = 0
      this.handlers.onOpen?.()
    }
    ws.onmessage = (msg: MessageEvent) => {
      try {
        const parsed = JSON.parse(String(msg.data)) as ServerEvent
        if (parsed && typeof parsed.event === 'string') this.handlers.onEvent(parsed)
      } catch {
        // 형식이 맞지 않는 메시지는 무시한다
      }
    }
    ws.onclose = (ev: CloseEvent) => {
      if (this.ws !== ws || this.stopped) return
      this.ws = null
      if (AUTH_FAIL_CODES.includes(ev.code)) {
        this.handlers.onAuthFailed?.(ev.code)
        return
      }
      const delay = reconnectDelay(this.attempt)
      this.attempt += 1
      this.timer = setTimeout(() => this.connect(), delay)
    }
  }
}

import type { BoxData, BoxState, BoxType, EdgeData, EdgeMode, GraphData } from './types'

export const BOX_TYPE_LABEL: Record<BoxType, string> = {
  common: '공통',
  personal: '개인',
  team: '팀',
  result: '결과',
}

export const EDGE_MODE_LABEL: Record<EdgeMode, string> = {
  auto: '자동',
  approval: '승인',
}

export const BOX_STATE_LABEL: Record<BoxState, string> = {
  locked: '잠김',
  open: '진행 중',
  closed: '완료',
}

// 노드에 붙는 표시용 정보. 에디터와 진행 화면이 각자 필요한 것만 채운다.
export interface BoxNodeData {
  box: BoxData
  state?: BoxState
  invalid?: boolean
  badge?: string
}

export interface FlowNode {
  id: string
  type: 'box'
  position: { x: number; y: number }
  data: BoxNodeData
}

export interface FlowEdge {
  id: string
  source: string
  target: string
  label: string
  animated: boolean
  class: string
  data: { mode: EdgeMode }
}

export interface NodeDecor {
  states?: Record<string, BoxState>
  invalidIds?: Iterable<string>
  badges?: Record<string, string>
}

export function toFlowNodes(graph: GraphData, decor: NodeDecor = {}): FlowNode[] {
  const invalid = new Set(decor.invalidIds ?? [])
  return graph.boxes.map((box) => ({
    id: box.id,
    type: 'box',
    position: { ...box.position },
    data: {
      box,
      state: decor.states?.[box.id],
      invalid: invalid.has(box.id),
      badge: decor.badges?.[box.id],
    },
  }))
}

export function toFlowEdge(edge: EdgeData, approved: Iterable<string> = []): FlowEdge {
  const isApproved = new Set(approved).has(edge.id)
  return {
    id: edge.id,
    source: edge.source,
    target: edge.target,
    label: EDGE_MODE_LABEL[edge.mode] + (isApproved ? ' ✓' : ''),
    animated: edge.mode === 'auto',
    class: `edge-${edge.mode}${isApproved ? ' edge-approved' : ''}`,
    data: { mode: edge.mode },
  }
}

export function toFlowEdges(graph: GraphData, approved: Iterable<string> = []): FlowEdge[] {
  const set = new Set(approved)
  return graph.edges.map((e) => toFlowEdge(e, set))
}

interface NodeLike {
  id: string
  position: { x: number; y: number }
  data?: { box: BoxData }
}

interface EdgeLike {
  id: string
  source: string
  target: string
  data?: { mode?: EdgeMode }
}

export function fromFlow(nodes: NodeLike[], edges: EdgeLike[]): GraphData {
  const boxes: BoxData[] = []
  for (const n of nodes) {
    if (!n.data?.box) continue
    boxes.push({ ...n.data.box, id: n.id, position: { x: Math.round(n.position.x), y: Math.round(n.position.y) } })
  }
  return {
    boxes,
    edges: edges.map((e) => ({
      id: e.id,
      source: e.source,
      target: e.target,
      mode: e.data?.mode ?? 'approval',
    })),
  }
}

export function uniqueId(prefix: string, taken: Iterable<string>): string {
  const used = new Set(taken)
  let n = 1
  while (used.has(`${prefix}-${n}`)) n += 1
  return `${prefix}-${n}`
}

export function newBox(type: BoxType, taken: Iterable<string>, position: { x: number; y: number }): BoxData {
  return {
    id: uniqueId(type, taken),
    type,
    title: `${BOX_TYPE_LABEL[type]} 박스`,
    position,
    config: { markdown: '', attachments_enabled: type !== 'result', editor: { files: [] } },
  }
}

export function newEdge(source: string, target: string, taken: Iterable<string>, mode: EdgeMode = 'auto'): EdgeData {
  return { id: uniqueId(`${source}-${target}`, taken), source, target, mode }
}

const LAYOUT_X = 260
const LAYOUT_Y = 120

/** 모든 박스가 같은 자리에 겹쳐 있으면(API로 만든 시험장 등) true. */
export function needsLayout(graph: GraphData): boolean {
  if (graph.boxes.length < 2) return false
  const first = graph.boxes[0]!.position
  return graph.boxes.every((b) => b.position.x === first.x && b.position.y === first.y)
}

/** 시작 박스에서의 가장 긴 거리(단계)로 열을, 같은 단계 안의 순서로 행을 정해 박스를 배치한다. */
export function autoLayout(graph: GraphData): GraphData {
  const depth = new Map<string, number>(graph.boxes.map((b) => [b.id, 0]))
  // 순환이 없으면 박스 수만큼 반복하면 충분하다. 순환이 있어도 끝나도록 횟수를 제한한다.
  for (let i = 0; i < graph.boxes.length; i += 1) {
    for (const e of graph.edges) {
      const next = (depth.get(e.source) ?? 0) + 1
      if (next > (depth.get(e.target) ?? 0) && next < graph.boxes.length) depth.set(e.target, next)
    }
  }
  const row = new Map<number, number>()
  const boxes = graph.boxes.map((b) => {
    const col = depth.get(b.id) ?? 0
    const r = row.get(col) ?? 0
    row.set(col, r + 1)
    return { ...b, position: { x: col * LAYOUT_X, y: r * LAYOUT_Y } }
  })
  return { ...graph, boxes }
}

export function hasEditor(type: BoxType): boolean {
  return type === 'personal' || type === 'team'
}

// 관리자 진행 화면용 계산. 화면과 무관한 순수 함수.
import type { AdminState, BoxState } from './types'

export interface Gate {
  target: string
  targetTitle: string
  edgeIds: string[]
  unsubmitted: string[]
}

/** 지금 승인할 수 있는 연결선을 도착 박스별로 묶는다. 출발 박스가 열린 적 있고 도착 박스가 잠겨 있어야 한다. */
export function pendingGates(state: AdminState): Gate[] {
  const approved = new Set(state.approved_edges)
  const boxState = (id: string): BoxState => state.boxes[id]?.state ?? 'locked'
  const gates = new Map<string, Gate>()
  for (const edge of state.graph.edges) {
    if (edge.mode !== 'approval' || approved.has(edge.id)) continue
    if (boxState(edge.source) === 'locked' || boxState(edge.target) !== 'locked') continue
    const target = state.graph.boxes.find((b) => b.id === edge.target)
    const source = state.graph.boxes.find((b) => b.id === edge.source)
    let gate = gates.get(edge.target)
    if (!gate) {
      gate = { target: edge.target, targetTitle: target?.title ?? edge.target, edgeIds: [], unsubmitted: [] }
      gates.set(edge.target, gate)
    }
    gate.edgeIds.push(edge.id)
    if (source?.type === 'personal' && !state.submissions[edge.source]) gate.unsubmitted.push(edge.source)
  }
  return [...gates.values()]
}

/** 관리자에게 보여 줄 배정 관련 경고. */
export function assignmentWarnings(state: AdminState): string[] {
  const personal = state.graph.boxes.filter((b) => b.type === 'personal')
  const assigned = new Set(state.participants.map((p) => p.assigned_box_id).filter(Boolean))
  const warnings: string[] = []
  const unassignedPeople = state.participants.filter((p) => !p.assigned_box_id).length
  const freeBoxes = personal.filter((b) => !assigned.has(b.id)).length
  if (unassignedPeople > 0 && freeBoxes === 0) {
    warnings.push(`배정할 개인 박스가 없는 참가자가 ${unassignedPeople}명 있습니다.`)
  }
  if (freeBoxes > 0 && state.run.status !== 'finished') {
    warnings.push(`아직 맡은 사람이 없는 개인 박스가 ${freeBoxes}개 있습니다.`)
  }
  if (state.participants.length > 0 && !state.participants.some((p) => p.is_leader)) {
    if (state.graph.boxes.some((b) => b.type === 'team')) warnings.push('팀장이 지정되지 않았습니다.')
  }
  return warnings
}

/** 진행 흐름도 노드에 붙일 짧은 표시(담당자, 제출 여부, 버전 수). */
export function boxBadges(state: AdminState): Record<string, string> {
  const badges: Record<string, string> = {}
  for (const box of state.graph.boxes) {
    if (box.type === 'personal') {
      const owner = state.participants.find((p) => p.assigned_box_id === box.id)
      const done = state.submissions[box.id] ? '제출' : '미제출'
      badges[box.id] = `${owner?.name ?? '미배정'} · ${done}`
    } else if (box.type === 'team') {
      const versions = state.team_versions[box.id] ?? []
      const final = versions.some((v) => v.is_final)
      badges[box.id] = final ? '최종 제출' : `버전 ${versions.length}개`
    }
  }
  return badges
}

export function boxStates(state: AdminState): Record<string, BoxState> {
  return Object.fromEntries(Object.entries(state.boxes).map(([id, b]) => [id, b.state]))
}

import { python } from '@codemirror/lang-python'
import { Compartment, EditorState } from '@codemirror/state'
import { EditorView, basicSetup } from 'codemirror'
import { onBeforeUnmount, onMounted, ref, watch } from 'vue'

const props = defineProps<{ modelValue: string; readonly?: boolean; label?: string }>()
const emit = defineEmits<{ 'update:modelValue': [value: string] }>()

const host = ref<HTMLDivElement>()
const editable = new Compartment()
let view: EditorView | null = null

function editableExtensions(readonly: boolean) {
  return [EditorState.readOnly.of(readonly), EditorView.editable.of(!readonly)]
}

onMounted(() => {
  view = new EditorView({
    parent: host.value!,
    state: EditorState.create({
      doc: props.modelValue,
      extensions: [
        basicSetup,
        python(),
        editable.of(editableExtensions(!!props.readonly)),
        EditorView.contentAttributes.of({ 'aria-label': props.label ?? '코드 입력' }),
        EditorView.updateListener.of((update) => {
          if (update.docChanged) emit('update:modelValue', update.state.doc.toString())
        }),
      ],
    }),
  })
})

watch(
  () => props.modelValue,
  (value) => {
    if (view && value !== view.state.doc.toString()) {
      view.dispatch({ changes: { from: 0, to: view.state.doc.length, insert: value } })
    }
  },
)

watch(
  () => props.readonly,
  (readonly) => view?.dispatch({ effects: editable.reconfigure(editableExtensions(!!readonly)) }),
)

onBeforeUnmount(() => view?.destroy())
</script>

<template>
  <div ref="host" class="code-editor" :class="{ readonly }" />

  }

  const t = await adminApi.getTemplate(templateId)

  description.value = t.description

  nodes.value = toFlowNodes(graph)
  edges.value = toFlowEdges(graph)
  showIssues(t.issues, t.valid)
  attachments.value = await adminApi.listTemplateFiles(templateId)
  dirty.value = false

async function guard(action: () => Promise<unknown>) {
  error.value = ''
  try {
    await action()
  } catch (e) {
    error.value = e instanceof ApiError ? e.message : '요청을 처리하지 못했습니다.'

// ---------------------------------------------------------------- 박스와 선
function select(nodeId: string | null, edgeId: string | null = null) {
  selectedNodeId.value = nodeId
  selectedEdgeId.value = edgeId
}

function addBox(type: BoxType, position?: { x: number; y: number }) {
  const at = position ?? { x: 80 + nodes.value.length * 40, y: 80 + nodes.value.length * 30 }
  const box = newBox(type, nodes.value.map((n) => n.id), at)
  nodes.value = [...nodes.value, ...toFlowNodes({ boxes: [box], edges: [] })]
  select(box.id)
  markDirty()
}

function onDragStart(event: DragEvent, type: BoxType) {
  event.dataTransfer?.setData(DRAG_TYPE, type)
  if (event.dataTransfer) event.dataTransfer.effectAllowed = 'move'
}

function onDrop(event: DragEvent) {
  const type = event.dataTransfer?.getData(DRAG_TYPE) as BoxType | undefined
  if (!type) return
  addBox(type, screenToFlowCoordinate({ x: event.clientX, y: event.clientY }))
}

onConnect((c: Connection) => {
  if (c.source === c.target) return
  if (edges.value.some((e) => e.source === c.source && e.target === c.target)) return
  const edge = newEdge(c.source, c.target, edges.value.map((e) => e.id))
  edges.value = [...edges.value, toFlowEdge(edge)]
  select(null, edge.id)
  markDirty()
})

function setEdgeMode(mode: EdgeMode) {
  const e = selectedEdge.value
  if (!e) return
  const updated = toFlowEdge({ id: e.id, source: e.source, target: e.target, mode })
  edges.value = edges.value.map((x) => (x.id === e.id ? updated : x))
  markDirty()
}

function removeSelected() {
  if (selectedNodeId.value) {
    const id = selectedNodeId.value
    nodes.value = nodes.value.filter((n) => n.id !== id)
    edges.value = edges.value.filter((e) => e.source !== id && e.target !== id)
  } else if (selectedEdgeId.value) {
    edges.value = edges.value.filter((e) => e.id !== selectedEdgeId.value)
  }
  select(null)
  markDirty()
}

function onNodesChange(changes: NodeChange[]) {
  if (changes.some((c) => c.type === 'remove')) markDirty()
}

function onEdgesChange(changes: EdgeChange[]) {
  if (changes.some((c) => c.type === 'remove')) markDirty()
}

// ---------------------------------------------------------------- 코드 파일
function addEditorFile() {
  const box = selectedBox.value
  const fileName = newFileName.value.trim()
  if (!box || !fileName || box.config.editor.files.some((f) => f.name === fileName)) return
  box.config.editor.files.push({ name: fileName, starter: '' })
  newFileName.value = ''
  markDirty()
}

function removeEditorFile(index: number) {
  selectedBox.value?.config.editor.files.splice(index, 1)
  markDirty()
}

// ---------------------------------------------------------------- 첨부 파일
const upload = (event: Event) =>
  guard(async () => {
    const input = event.target as HTMLInputElement
    const file = input.files?.[0]
    if (!file || !selectedNodeId.value) return
    await adminApi.uploadTemplateFile(templateId, selectedNodeId.value, file)
    input.value = ''
    attachments.value = await adminApi.listTemplateFiles(templateId)
  })

const removeAttachment = (file: StoredFile) =>
  guard(async () => {
    await adminApi.deleteTemplateFile(templateId, file.id)
    attachments.value = await adminApi.listTemplateFiles(templateId)
  })

// ---------------------------------------------------------------- 저장과 회차
const save = () =>
  guard(async () => {
    const t = await adminApi.saveTemplate(templateId, {
      name: name.value,
      description: description.value,
      graph: fromFlow(nodes.value, edges.value),
    })
    showIssues(t.issues, t.valid)
    dirty.value = false
    message.value = t.valid ? '저장했습니다. 회차를 열 수 있습니다.' : '저장했습니다. 아래 문제를 고쳐야 회차를 열 수 있습니다.'
  })

const openRun = () =>
  guard(async () => {
    const runName = window.prompt('회차 이름', `${new Date().toLocaleDateString('ko-KR')} 회차`)
    if (!runName) return
    const run = await adminApi.createRun(templateId, runName)
    await router.push(`/admin/runs/${run.id}`)
  })

onMounted(() => guard(load))
</script>

// 참가자 작업 화면용 계산과 개인 단계 임시 저장(localStorage). 화면과 무관한 순수 함수.
import type { Files, ParticipantBox, ParticipantState } from './types'

export function draftKey(runId: number, boxId: string): string {
  return `ctw.draft.${runId}.${boxId}`
}

export function loadDraft(runId: number, boxId: string): Files | null {
  const raw = localStorage.getItem(draftKey(runId, boxId))
  if (!raw) return null
  try {
    return JSON.parse(raw) as Files
  } catch {
    return null
  }
}

export function saveDraft(runId: number, boxId: string, files: Files): void {
  localStorage.setItem(draftKey(runId, boxId), JSON.stringify(files))
}

/** 개인 박스 편집기의 처음 내용: 브라우저 임시본 > 마지막 제출본 > 시작 코드. 파일 목록은 박스 설정을 따른다. */
export function initialFiles(box: ParticipantBox, submitted: Files | null, draft: Files | null): Files {
  const files: Files = {}
  for (const f of box.editor_files ?? []) {
    files[f.name] = draft?.[f.name] ?? submitted?.[f.name] ?? f.starter
  }
  return files
}

/** 처음 열어 줄 박스: 열린 팀 박스 > 내 열린 개인 박스 > 열린 공통 박스 > 첫 박스. */
export function defaultBoxId(state: ParticipantState): string | null {
  const open = (type: ParticipantBox['type']) => state.boxes.find((b) => b.type === type && b.state === 'open')
  return (open('team') ?? open('personal') ?? open('common') ?? state.boxes[0])?.id ?? null
}

export function isWaiting(state: ParticipantState): boolean {
  if (state.run.status === 'lobby') return true
  return !state.me.assigned_box_id && !state.boxes.some((b) => b.state !== 'locked')
}

    await participantApi.state()
    await router.push('/run')
    return true
  } catch (e) {
    if (e instanceof ApiError && e.status === 409) pending.value = true
    return false
  }
}

function startPolling() {
  poll = setInterval(async () => {
    if (await tryEnter()) stopPolling()
  }, POLL_MS)
}

function stopPolling() {
  if (poll) clearInterval(poll)
  poll = null
}

async function submit() {
  busy.value = true
  error.value = ''
  try {
    const joined = await participantApi.join(entryCode.value, name.value)
    saveParticipant({ token: joined.token, runId: joined.run_id, participantId: joined.participant_id })
    if (joined.status === 'pending') {
      pending.value = true
      startPolling()
    } else {
      await router.push('/run')
    }
  } catch (e) {
    error.value = e instanceof ApiError ? e.message : '입장하지 못했습니다.'
  } finally {
    busy.value = false
  }
}

onMounted(async () => {
  if (loadParticipant() && !(await tryEnter()) && pending.value) startPolling()
})
onBeforeUnmount(stopPolling)
</script>
